════════════════════════════════════
РАЗВЁРНУТОЕ ОПИСАНИЕ (для лендинга, "О сервисе")
════════════════════════════════════

Зачем разбираться в подписках OpenAI, Anthropic и Google по отдельности,
если можно зайти в одно окно?

«Мульти» — это не ещё одна нейросеть, а удобная надстройка над всеми
крупными моделями ИИ сразу. Открываете чат, выбираете модель (или
доверяете выбор системе) и получаете ответ — без переключения между
вкладками и разными аккаунтами.

Что внутри:
— Доступ к моделям всех крупных лабораторий в одном интерфейсе
— Режим «Авто»: система сама анализирует ваш вопрос и подбирает
  подходящую модель — для кода одну, для творческой задачи другую
— Бесплатные модели без ограничений по количеству использований в день —
  доступны каждому без необходимости платить
— Прозрачная система кредитов: платите только за фактическое использование,
  без ежемесячной подписки, которая тратится впустую в тихие месяцы

Для кого:
— Для тех, кто хочет сравнивать ответы разных моделей на один и тот же
  вопрос
— Для тех, кто устал платить за 3-4 подписки одновременно
— Для тех, кто просто хочет один удобный чат с ИИ без лишних решений —
  что выбрать, решит автоподбор

════════════════════════════════════
СОВЕТ ПО ПОЗИЦИОНИРОВАНИЮ
════════════════════════════════════

Не называйте сервис "ещё одним ChatGPT" — это создаёт ложное ожидание
собственной модели. Ключевое УТП — агрегация и удобство выбора, а не
качество конкретной модели (это не в вашей власти, вы просто даёте
доступ к чужим моделям через OpenRouter). Делайте акцент на:
1) экономии (не нужно 3-4 подписки)
2) удобстве (не нужно помнить, где какая модель сильнее)
3) бесплатном входе (можно попробовать без карты)
