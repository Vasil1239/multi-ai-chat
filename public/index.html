Установка на телефон

AskHub можно поставить как приложение — с иконкой на рабочем столе и без адресной строки. Занимает меньше 1 МБ.

iPhone / iPad · Safari

  1. Откройте askhub.net в Safari (не в Chrome и не в Telegram-браузере)
  2. Нажмите кнопку «Поделиться» внизу экрана ↑
  3. Пролистайте меню и выберите «На экран Домой» ＋
  4. Нажмите «Добавить» в правом верхнем углу

Иконка AskHub появится на главном экране. Запускается как обычное приложение — без адресной строки и вкладок.

Android · Chrome

  1. Откройте askhub.net в Chrome
  2. Нажмите на плавающую кнопку «📱 Установить на телефон» внизу справа
  3. Или откройте меню Chrome ⋮ и выберите «Установить приложение»
  4. Подтвердите — иконка появится на рабочем столе

Chrome может показать баннер «Добавить AskHub на главный экран» автоматически при повторном визите.

Компьютер · Chrome / Edge

  1. Откройте askhub.net в Chrome или Edge
  2. Справа в адресной строке появится иконка «Установить» ⊕
  3. Нажмите её и подтвердите — AskHub появится в списке приложений и на панели задач
  4. Запускается в отдельном окне без вкладок и адресной строки

Работает на Windows, macOS и Linux — везде, где есть Chrome, Edge или Brave.
