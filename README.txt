МУЛЬТИ v3 — ВСЕ МОДЕЛИ + АВТОПОДБОР + МОНЕТИЗАЦИЯ + ЗАЩИТА ДОСТУПА

ЧТО ДОБАВЛЕНО В ЭТОЙ ВЕРСИИ (v3):

— Кредиты теперь списываются по РЕАЛЬНОЙ стоимости обращения к модели
  (на основе фактически потраченных токенов и цены конкретной модели
  в OpenRouter), а не фиксированно по 1 кредиту за любое сообщение.
  Дешёвые модели могут стоить меньше кредита (округляется до 1 — минимум),
  дорогие топовые модели — несколько кредитов за сообщение.
  1 кредит ~ $0.01 реальной себестоимости в OpenRouter.

— Необязательная защита сайта кодом доступа. Если задать переменную
  окружения SITE_ACCESS_CODE — все посетители должны будут ввести этот
  код перед тем, как попасть в чат. Если переменную не задавать —
  сайт открыт всем как раньше. Это ПРОСТАЯ защита от случайных
  посетителей и ботов, не полноценная авторизация — код общий для всех,
  кому вы его дадите.

— Страница /legal.html — шаблон условий использования и политики
  возврата. ОБЯЗАТЕЛЬНО замените плейсхолдеры [...] на свои данные
  и, по-хорошему, покажите юристу перед реальным запуском с платежами.

— marketing_copy.txt — готовые тексты для продвижения: короткое
  описание, пост для соцсетей, текст для лендинга, описание товара
  для Stripe.

НОВАЯ ПЕРЕМЕННАЯ ОКРУЖЕНИЯ (необязательная):
  SITE_ACCESS_CODE = любой код по вашему выбору, например "tarot2026"
  (если не заполнять — защиты нет, сайт открыт всем)



— Вместо прямых ключей к OpenAI/Anthropic/Google теперь один ключ OpenRouter,
  который даёт доступ к 400+ моделям от всех крупных лабораторий сразу
  (OpenAI, Anthropic, Google, xAI, DeepSeek, Moonshot AI, Meta, Mistral и др.)
  Список моделей подгружается автоматически — ничего вручную прописывать не надо.

— Модели, у которых цена $0 за токен, помечены в интерфейсе как "бесплатно"
  и не расходуют кредиты пользователя.

— Появился режим "Авто" — OpenRouter сам классифицирует запрос
  (код, творческий текст, быстрый факт и т.д.) и выбирает подходящую модель.
  Это тот же принцип, по которому работают Perplexity, Poe (Quora) и T3 Chat —
  они называют это "auto router" / "smart routing".

— Появился режим "Бесплатные" — всегда бесплатная модель, OpenRouter
  сам выбирает из доступных на данный момент бесплатных моделей.

— Добавлена система кредитов для монетизации:
  каждый новый пользователь получает 20 бесплатных кредитов,
  дальше — 1 кредит за сообщение к платной модели (бесплатные модели
  кредиты не тратят), пополнение баланса — через Stripe.

СТРУКТУРА ПРОЕКТА:
  public/index.html                     — интерфейс
  netlify/functions/models.js           — отдаёт список моделей OpenRouter
  netlify/functions/chat.js             — отправляет сообщение, списывает кредит
  netlify/functions/credits.js          — баланс пользователя
  netlify/functions/create-checkout.js  — создаёт Stripe-оплату
  netlify/functions/stripe-webhook.js   — начисляет кредиты после оплаты
  package.json                          — зависимости (@netlify/blobs, stripe)
  netlify.toml                          — конфигурация

ШАГИ ПУБЛИКАЦИИ:

1. Получите ключ OpenRouter (один ключ — доступ ко всем моделям)
   https://openrouter.ai/settings/keys
   Пополните баланс на нужную сумму (или начните с бесплатных моделей —
   для них баланс не нужен вовсе).

2. Зарегистрируйтесь на Netlify
   https://app.netlify.com/signup

3. Загрузите проект через GitHub (для этой версии обязательно —
   Netlify Drop не устанавливает npm-зависимости):
   — Создайте репозиторий: https://github.com/new
   — Загрузите туда всю папку multi-ai
   — На https://app.netlify.com нажмите "Add new site" -> "Import an existing project"
   — Подключите GitHub и выберите репозиторий

4. Добавьте переменные окружения
   Site configuration -> Environment variables -> Add a variable

     OPENROUTER_API_KEY    = ваш ключ с шага 1  (обязательно)
     STRIPE_SECRET_KEY     = ваш секретный ключ Stripe (для приёма оплат)
     STRIPE_WEBHOOK_SECRET = секрет вебхука Stripe (см. шаг 6)

   Без Stripe-ключей сайт всё равно будет работать — просто кнопка
   "Пополнить" не сработает, а бесплатные модели будут доступны всем.

5. Пересоберите сайт
   Site configuration -> Deploys -> Trigger deploy -> Deploy site

6. Настройте приём оплат Stripe (если хотите монетизировать)
   — Зарегистрируйтесь на https://dashboard.stripe.com/register
   — Ключи: https://dashboard.stripe.com/apikeys (используйте live-ключи
     для реальных платежей, test-ключи — для проверки)
   — Настройте вебхук: https://dashboard.stripe.com/webhooks -> Add endpoint
     URL: https://ваш-сайт.netlify.app/.netlify/functions/stripe-webhook
     Событие для подписки: checkout.session.completed
   — Скопируйте "Signing secret" вебхука в переменную STRIPE_WEBHOOK_SECRET

7. Готово — откройте https://ваш-сайт.netlify.app

КАК УСТРОЕНА ИДЕНТИФИКАЦИЯ ПОЛЬЗОВАТЕЛЕЙ (ВАЖНОЕ ОГРАНИЧЕНИЕ):
Сейчас пользователь идентифицируется просто по email без пароля —
это самый простой способ связать баланс кредитов с человеком между
визитами, но это НЕ настоящая авторизация: кто угодно, кто введёт
чужой email, увидит тот же баланс. Для полноценного продукта стоит
добавить настоящую аутентификацию (например, Supabase Auth с magic-link
письмами или Netlify Identity) — могу дописать, если понадобится
реальный запуск с деньгами пользователей.

ЭКОНОМИКА:
— Хостинг Netlify — бесплатно (в рамках щедрого бесплатного тарифа)
— OpenRouter берёт стандартную цену провайдера за платные модели,
  без наценки сверху
— Ваша выручка = деньги за проданные пакеты кредитов минус то, что вы
  реально потратите на OpenRouter за платные модели. Разница — ваша маржа.
— Бесплатные модели ничего не стоят ни вам, ни пользователю — это способ
  привлечь людей на сайт без риска для вашего баланса.

ЧТО МОЖНО ДОБАВИТЬ ДАЛЬШЕ (если понадобится):
— Настоящая аутентификация вместо email без пароля
— Разная стоимость кредита в зависимости от модели (сейчас любая платная
  модель стоит 1 кредит, хотя реальная себестоимость моделей отличается
  в десятки раз — это упрощение для MVP)
— История чатов, сохранённая на сервере (сейчас хранится только в памяти
  браузера на время сессии)
— Реферальная программа / промокоды
